# Git-põhine versioonikontroll algajatele

Loeng-praktikum bioinformaatika ja meditsiini tudengitele ja teaduritele. 2 tundi, laieneb lisaplokkidega 4 tunnini.

## Osalejale

1. **[Eeltöö](eeltoo.md)** – tee läbi enne loengut, 20–30 min. Git, terminal, GitHubi konto, `gh auth login`.
2. **[Praktikumi juhend](praktikum.md)** – ava loengu alguses, käsud on kopeerimiseks.
3. **[Näidisrepo](https://github.com/tpall/git-praktikum-naidis)** – kloonid praktikumi osas 2.4.

## Õppejõule

- [`kava.md`](kava.md) – ajakava, lisaplokid, ettevalmistus, tüüpilised probleemid.
- [`slaidid.qmd`](slaidid.qmd) – Quarto reveal.js slaidid, `quarto render slaidid.qmd`.
